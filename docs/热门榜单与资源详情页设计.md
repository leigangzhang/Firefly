# 热门榜单页与资源详情页设计

入口：Jellyfin 顶栏火焰图标 → 整页打开"热门榜单"（覆盖 Jellyfin 页面，Esc 或 ✕ 关闭）。点海报进入"资源详情页"，"← 返回榜单"回到原来的滚动位置。数据全部来自 TMDb（用户自己的 API Key），插件内存缓存：列表 30 分钟、详情 6 小时、类型表 24 小时。

## 1. 热门榜单页（参考爱奇艺"看影剧"）

| 筛选行 | 选项来源 | TMDb `/discover` 参数 |
|---|---|---|
| 分类 | 规则文件 `discover.categories`：电影 / 剧集 / 动漫 / 纪录片 / 综艺 | 电影 → `/discover/movie`；其余 → `/discover/tv`，并带分类自带的类型限制（动漫 `with_genres=16`，纪录片 `99`，综艺 `10764\|10767`，剧集排除这些） |
| 类型 | TMDb `/genre/{movie\|tv}/list`（中文） | `with_genres`（与分类自带类型取"且"） |
| 地区 | 规则文件 `discover.regions` | `with_origin_country` |
| 时间 | 最近 7 年逐年 + 三个十年段 + 更早，按当前年份生成 | 电影 `primary_release_date.gte/lte`，剧集 `first_air_date.gte/lte` |
| 出品 | 电影：`discover.companies`（制片公司）；剧集类：`discover.networks`（平台/电视台） | `with_companies` / `with_networks` |
| 推荐 | 最热 / 最新 / 高分 / 最多评价 | `popularity.desc`；剧集类“最热”限定最近两年（未显式选时间时）；日期倒序且只看已上映；`vote_average.desc` + 最少评价数（电影 300、剧集 150）；`vote_count.desc` |
| 分级 | `discover.certifications`（美国分级 G / PG / PG-13 / R / NC-17），仅电影 | `certification_country=US&certification=…`（TMDb 不支持按分级筛剧集，剧集类不显示这一行） |

- 换分类时，新分类不存在的选项（类型、出品、分级）自动清掉，地区、时间保留；推荐排序重置为电影默认的“最热”。
- 列表沿用原来的海报卡片网格，海报右下角显示 TMDb 评分（≥7.5 橙色），左上角"已在库"，下方片名 + 年份 · 前两个类型。滚动到底自动加载下一页（每页 20 条，TMDb 最多 500 页）。
- 公司 / 电视网 ID 写在规则文件里：发现某个 ID 不对时，在数据目录放一个 `rules.json` 覆盖即可，不用发版。

### 搜索

- 榜单页顶栏右上角是搜索框，输入片名后停顿约半秒自动搜索（回车立即搜），调用 TMDb `/search/multi`，只保留电影和剧集。
- 搜索结果替换榜单区域，用同样的海报卡片（副标题标明电影 / 剧集），滚动加载更多；点卡片进入详情页，返回时回到搜索结果。
- 清空搜索框、点"返回榜单"或在搜索框里按 Esc，恢复原来的榜单、筛选和滚动位置。

## 2. 资源详情页（参考 TMDb 影剧详情页）

一次请求取回：`/{movie|tv}/{id}?append_to_response=videos,credits|aggregate_credits,release_dates|content_ratings,watch/providers&include_video_language=zh,en,null`。

- **头部**：背景大图 + 左侧海报；片名（年份）、原名；分级徽标 · 上映/首播日期 · 类型 · 片长；用户评分环；操作按钮 **收藏**、**下载**、**播放预告片**；"已在库"标记；标语；导演/编剧（剧集为主创）。
- **主栏，从上到下**：
  1. 剧情介绍；
  2. 预告片：内嵌 YouTube 播放器（youtube-nocookie），点封面才加载；预告排在先导前，中文优先；多个视频可切换；附"在 YouTube 打开"链接（YouTube 打不开时用）；
  3. 导演 & 演员：横向人物卡（头像、姓名、角色；剧集显示出演集数）；
  4. 剧集额外显示分季卡片：默认只显示当前季（最近播出那一集所在的季），点"查看全部季"在下方展开其余各季。卡片含季海报、季名、季评分、年份 · 集数、季简介，底部是这一季最近播出的一集（集名、SxE、播出日期）。最近一集来自 `/tv/{id}/season/{n}`，每张卡片单独请求并缓存。
- **右侧栏**：资源类型（电影 / 剧集 / 动漫 / 纪录片 / 综艺 / 动画电影）、状态、原始片名、原始语言、上映/首播日期、出品地区、季/集数、片长、分级、播出平台（剧集的电视网 logo）、在线播放（TMDb/JustWatch 数据，先找中国区，没有再用美国区）、租赁/购买、出品方、预算、票房、官网、TMDb 链接。
- **收藏**：保存在数据目录 `favorites.json`，榜单页顶栏"我的收藏"查看。
- **下载**：沿用原来的"获取资源"面板（剧集先选季，季数来自 TMDb）。

## 3. 获取资源 / 下载任务抽屉

- 原来的居中弹窗改为右侧抽屉（宽 600px，手机全宽），配色与榜单页、详情页一致；背景变暗并轻微模糊，抽屉滑入滑出，Esc 或点背景关闭。
- 抽屉顶部两个标签"资源版本"和"下载任务"，切换时抽屉不关闭，内容淡入；"下载任务"标签上显示进行中任务数。
- 资源版本：季用标签切换（不再是下拉框）；免费额度显示为进度条；加载时显示骨架屏；每个版本是一张卡片，分辨率高亮、发布者绿色标签；点"下载"后按钮变为"✓ 已交给迅雷"，底部提示可一键跳到下载任务。
- 下载任务：每个任务一张卡片，状态带图标和颜色（下载中黄色条纹动画、停滞橙色、失败红色、已入库绿色）；每 5 秒按任务 ID 原地更新，进度条平滑前进、不闪烁；移除时卡片滑出。
- 来源隐藏：版本和任务只显示干净名称，如"牵牛和仙女 S01 全12集"（片名、季、集数范围；画质在下方标签里），发布站只显示为"优选"标签。`/FireFly/search` 不再下发原始发布名、磁力、搜索词和出错的源地址；提交下载只传版本 ID（InfoHash），服务端从搜索缓存（6 小时）里找回完整版本。交给迅雷的磁力里 `dn` 换成干净名称，原始名只留在服务端用于匹配下载目录里的文件。

## 4. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/FireFly/discover/filters?category=` | 筛选行 + 类型 ID→名称表 |
| GET | `/FireFly/discover?category=&genre=&region=&time=&company=&sort=&rating=&page=` | 榜单一页 |
| GET | `/FireFly/discover/search?q=&page=` | 按片名搜电影和剧集 |
| GET | `/FireFly/detail/{movie\|tv}/{tmdbId}` | 详情 + 是否在库 + 是否已收藏 |
| GET | `/FireFly/detail/tv/{tmdbId}/season/{n}` | 某一季最近播出的一集 |
| POST | `/FireFly/tasks` | 提交下载：`{ query, releaseId }` |
| GET / POST | `/FireFly/favorites` | 收藏列表 / 加入收藏 |
| DELETE | `/FireFly/favorites/{movie\|tv}/{tmdbId}` | 取消收藏 |
