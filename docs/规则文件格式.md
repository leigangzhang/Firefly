# 规则文件格式

FireFly 把会随上游变化的东西都放在规则文件里：搜索源的地址和响应格式、发布者关键词、迅雷临时文件后缀、视频 / 字幕扩展名、热门榜单的筛选目录、配置页里可选的 TMDb 地址。站点换域名或改字段时只改规则，不用改代码、不用发版。

## 加载顺序

1. **内置规则**：`src/FireFly.Core/Rules/rules.default.json`，编进插件 DLL，随插件版本更新。
2. **本地覆盖**：插件数据目录里的 `rules.json`（Jellyfin.app 默认为 `~/Library/Application Support/jellyfin/plugins/FireFly.Jellyfin`），可选。改完后重启 Jellyfin 生效。

覆盖文件按字段**叠加**到内置规则上，只需要写要改的部分：

| 位置 | 叠加方式 |
|---|---|
| 对象（如 `thunder`、`discover`、某个源的 `response`） | 逐个字段覆盖，没写的字段保留内置值 |
| `sources` 数组 | 按 `name` 合并：同名的源只覆盖写到的字段；新名字追加在内置源之后 |
| 其他数组（如 `publisherKeywords`、`discover.companies`） | 整体替换 |

以下情况会忽略覆盖文件、使用内置规则，并在配置页的"规则提示"里说明原因：

- `rules.json` 不是合法 JSON；
- `format` 高于插件支持的格式版本（说明规则是给更新的插件写的，需要升级插件）；
- 文件没有 `format` 字段且 `version` 低于内置规则版本：这是 0.2 及以前整份拷贝出来的旧规则，叠加上去会把新版内置规则改回旧的。

类型不认识、缺少 `endpoints` 或 `response.itemsPath` 的源会被跳过，同样显示在"规则提示"里。

## 版本字段

- `format`：文件结构的版本，当前为 `1`。只有不兼容地改结构时才加一；旧插件看到更高的 `format` 会拒绝读取。覆盖文件可以不写，按 `1` 处理。
- `version`：内置规则内容的版本，每次改 `rules.default.json` 加一。覆盖文件里的 `version` 不参与叠加。

## 搜索源（`sources[]`）

目前只有一种类型 `jsonApi`：按 GET 请求一个返回 JSON 的搜索接口，按路径取出种子列表和字段。

| 字段 | 说明 | 默认 |
|---|---|---|
| `name` | 源的名字，也是覆盖时的合并键 | 必填 |
| `kind` | `jsonApi` | 必填 |
| `endpoints` | 同一个源的多个镜像地址，依次尝试，上次成功的排到最前 | 必填 |
| `pageSize` / `maxPages` | 每页条数、最多翻几页 | 10 / 1 |
| `enabled` | 设成 `false` 可停用一个内置源 | `true` |
| `request.keywordParam` / `limitParam` / `offsetParam` | 查询参数名 | `keyword` / `limit` / `offset` |
| `request.maxLimit` | 站点允许的单页上限，`pageSize` 超过时截断 | 10 |
| `response.statusPath` / `statusOk` / `messagePath` | 业务状态码路径、成功值、错误信息路径；`statusPath` 为空表示不检查 | 空 / `"200"` / 空 |
| `response.itemsPath` | 种子列表所在路径 | 必填 |
| `response.hasMorePath` | "还有下一页"标志路径；为空时本页取满就继续翻 | 空 |
| `response.fields.*` | 每一项里的字段路径：`infoHash`、`name`、`magnet`、`size`、`createdAt`、`files`（数组，其中每项用 `filePath`、`fileSize`） | `hash`、`name`，其余为空 |
| `response.fields.createdAtFormat` | `unix`（秒）或 `iso` | `unix` |

路径用点分隔，如 `data.torrents`。`magnet` 取不到时用 `infoHash` 拼磁力；数字字段接受数字或数字字符串。

## TMDb 地址（`tmdb`）

`tmdb.apiBases` 和 `tmdb.imageBases` 是配置页"TMDb 元数据地址""TMDb 图片地址"下拉框的候选项，每项是 `{ "value": 地址, "label": 显示文字 }`，第一项是默认值。插件直连这些地址，不经过中转；海报也由插件取回并缓存，浏览器只从 Jellyfin 加载。默认入口被屏蔽后，社区可以在内置规则里补充可用地址；用户也可以在覆盖文件里写一份新列表（数组整体替换），或在配置页选"自定义"直接填。

## 示例

站点换了域名，只改地址：

```json
{
  "sources": [
    { "name": "diao.im", "endpoints": ["https://新域名/api/search"] }
  ]
}
```

停用内置源、改用自己的接口：

```json
{
  "sources": [
    { "name": "diao.im", "enabled": false },
    {
      "name": "my-api",
      "kind": "jsonApi",
      "endpoints": ["https://example.com/search"],
      "response": {
        "itemsPath": "results",
        "fields": { "infoHash": "btih", "name": "title", "size": "bytes", "createdAt": "date", "createdAtFormat": "iso" }
      }
    }
  ]
}
```

修正一个制片公司的 TMDb ID（数组整体替换，要写全）：

```json
{ "discover": { "companies": [ { "value": "174", "label": "华纳兄弟" } ] } }
```
